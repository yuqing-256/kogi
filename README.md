# 幕末日本转型（1853–1877）· 公共历史项目

解释日本如何从德川幕藩体制下的政治秩序，经内外危机、政治合法性竞争、权力重组与战争，
形成明治初期的新国家秩序；说明转型为何发生、哪些可能性未能实现、不同群体各扮演什么角色。
研究先于工程：进展以历史问题的推进衡量，保留反证、争议、未知与未实现的可能性。

## 状态

- 阶段：P0 研究期（只允许 research 与 stage-review）
- 每日循环：18:01（Asia/Shanghai）；调度预检与耐久性限制见 `research/log.md`
- 默认不发布；媒体、隐私、发布相关目录与依赖在对应阶段前不创建

## 范围

- 主时段约 1853–1877（黑船来航至西南战争），日本列岛及相关国际环境
- 背景追溯：幕藩体制与对外关系；结尾延伸：明治国家建设后期
- 边界细化在研究中提出，并记 `[decision]`

## 目录

- `README.md`：项目说明与运行摘要
- `mise.toml`：P0 工具声明（仅 uv，按需安装）
- `research/queue.md`：研究问题与队列
- `research/sources.tsv`：来源登记
- `research/claims.tsv`：论断登记
- `research/log.md`：运行日志、决定与阶段
- `research/notes/`：研究记录（首个研究任务时创建，`Q-###.md`）

## 方法与产出

- 方法：史料批判、史学争议梳理、多方视角比较、证据核验、公共阐释；范式按需引入并记 `[decision]`
- 产出：网站、博客、视频、出版物，均由同一套经核验成果生成；P2 前不建目录、不选型

## 运行规则（摘要）

- 每日只做一个主要任务类型；P0 只研究或阶段评审
- 研究任务必须对应 `research/queue.md` 条目；开工前检索已有来源、论断与日志
- 阶段切换只在 stage-review 中进行；进入阶段时先写下一阶段判定条件，冷却期 7 天
- 稳定编号：Q-###（问题）、S-###（来源）、C-###（论断）；不伪造引用，不写百分比置信度
- 记录证据缺口、史学争议、未知事项与未实现的可能性
- 每天至多一次 Git 提交；工具或提交失败时记录实际状态并停止，不重试

## 登记约定

- `research/sources.tsv`：id、bibliographic、language_version、type、locator、read_status（已读取/仅见他处引用）、assessment_status（待评估/已初步评估/存在争议）、assessment_reason
- `research/claims.tsv`：id、statement、source_ids、evidence_relation（支持/反证/背景）、status（待支持/有证据支持/存在反证/有争议）、limitations
- 仅见他处引用的来源不得单独支撑论断；无法核验的内容必须标记，不得把推测写成事实
